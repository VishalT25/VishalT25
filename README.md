### projects
 
**[StuCo](https://github.com/VishalT25/StuCo)** &nbsp;·&nbsp; `Swift` `SwiftUI` `Supabase` `iOS`  
an iOS scheduling app that takes unstructured academic content and converts it into calendar events using an AI extraction pipeline. >97% recognition accuracy in testing. built with offline-first architecture, subscription gating, and production-grade error handling.
 
**[DuckSpeak](https://github.com/VishalT25/DuckSpeak)** &nbsp;·&nbsp; `Python` `React` `MediaPipe` `TypeScript`  
real-time ASL-to-text accessibility tool built at HackHarvard 2025. runs at 25–30 FPS with <30ms inference latency, >90% gesture stability across 2,000+ test samples. tightened the prediction loop to cut caption flicker during continuous signing.
 
**[ParlayBud](https://github.com/VishalT25/ParlayBud)** &nbsp;·&nbsp; `Python` `XGBoost` `SvelteKit` `ML`  
NBA parlay prediction dashboard powered by XGBoost, trained on 34,000+ game logs (AUC 0.63). full-stack: data ingestion → feature engineering → model training → interactive SvelteKit dashboard with real-time prediction outputs.
